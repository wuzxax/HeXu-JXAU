<h1 align="center">禾序 · Hexu</h1>
<p align="center">面向江西农业大学学生的 Android 校园生活助手</p>

禾序把每天最常用的几件事放在一个 App 里。打开首页就能看今天有哪些课和日程，去课表里调整自己的安排，再到学习通查作业、图书馆搜书，或在接水页查看用水花费。熟悉的校园服务可以从首页进入，需要由平台办理的操作会打开对应的官方入口。

禾序是个人维护的第三方项目，软件仅供学习交流使用如有侵权请联系删除侵权部分，与江西农业大学及所接入的服务平台无隶属关系。

## 下载安装

1. 打开 [Releases](https://github.com/wuzxax/HeXu-JXAU/releases)，进入最新正式版本。
2. 在 **Assets** 中下载以 `.apk` 结尾的安装包，例如 `Hexu-v3.5.12.apk`。
3. 在 Android 手机上打开 APK。如果系统询问是否允许浏览器或文件管理器安装应用，按系统提示完成安装。
4. 第一次打开可以到「我的 → 登录与使用指南」，按需要登录各项服务。已有正式版的用户可以直接覆盖升级。

最低支持 **Android 7.0**。桌面组件、课程上岛和自动免打扰的可用性取决于 Android 版本与手机系统。iPhone 暂无对应版本。

| 想使用的功能 | 从哪里开始 |
| --- | --- |
| 同步课表、查成绩、看个人借阅记录 | 到「我的 → 账号与绑定」登录学校统一身份认证。登录时输入学号、密码和图片算式的答案。 |
| 看学习通作业 | 在底栏打开「学习通」，点「绑定学习通」，使用学习通账号登录。 |
| 接水、看余额与花费 | 在底栏打开「接水」，进入「账号与钱包管理」，用 798 手机号和验证码完成绑定。 |

## 主要功能

### 今日与学期课表

- **首页今日安排**显示尚未结束的课程和自定义日程。进行中的安排优先显示，结束后再提示当天的下一项。当天结束后显示收尾提示。
- **学期课表**以网格展示，左右滑动切周，点课程查看教室和时间。同步后的课表可离线查看。在「课表 → 工具 → 课表背景」可选本机图片，调整浓度并预览当前周的实际课表。登录过期时，可从刷新入口重新登录。
- **自定义日程**可以点课表空白处或「＋ 添加」新建，填写地点或备注，选择生效周次。可设为仅当前周生效。再次点日程即可编辑，也可在课表里拖动边缘，以五分钟为步长调整时长。
- **早检和晚自习**在「我的 → 课表设置」中配置。早检可选星期、教室与起止时间。晚自习可选星期、周次和教室。两项都可以在课表设置内关闭。
- **课表工具**支持仅修改或取消一次课，也可以记录学校调休和补课。误改后可在修改记录里撤回或重做。支持导出当前周图片，以及当前周或学期的 ICS 日历。调整只应用于禾序本地课表，学校安排以教务系统为准。

### 学习通作业

在「学习通」可以按截止时间或课程查看作业，也可以筛选待完成、已完成的记录。课程选择显示全名。课程较多时分批读取，已读取的作业会逐步显示。平台暂时限制访问时，禾序会停下并保留当前结果，可按提示继续。

点开作业可查看应用支持的题目和附件。已适配题型可在禾序中作答、保存草稿并确认提交。已提交的作业会尽量沿用平台返回的状态。遇到额外验证、提交结果待确认或暂未适配的题型，可到学习通核对或继续作答。

### 图书馆、成绩、快递与电费

| 入口 | 可以做什么 |
| --- | --- |
| 「今日 → 常用服务 → 图书馆」 | 按书名等信息检索，查看书目详情和馆藏位置。登录后可查看个人借阅、历史与到期信息。 |
| 「今日 → 常用服务 → 成绩查询」 | 读取教务成绩，按学期筛选，展开平时成绩、考试成绩等学校已提供的字段。 |
| 「今日 → 常用服务 → 快递取件」 | 打开菜鸟、淘宝、拼多多等平台的身份码或包裹入口。是否直达取件界面取决于官方 App 版本及登录状态。 |
| 「今日 → 校园钱包」 | 查询已绑定宿舍的空调电费和用电趋势，通过完美校园缴费。照明电费请在完美校园查询和办理。 |

### 798 接水与用水账单

绑定自己的慧生活 798 账号后，可以扫设备上的二维码或手动输入编号。常用饮水机保存后，可直接在「我的饮水机」点击接水。发送请求后请在水机上及时确认，用完及时结束。绑定禾序后，使用慧生活 798 官方 App 时可能需要重新登录。

- **饮水花费**按日、周、月查看，主页面用 **0.20 元／升**估算今日饮水量。
- **洗浴花费**按周、月查看，并展示本月次均花费。
- 点击花费卡片查看趋势和账单。禾序使用已读取并保存到本机的记录做统计，历史覆盖范围取决于账单同步情况。
- 水卡余额和设备列表可收起。首页「校园钱包」里的 798 区域可切换为「用水花费」。

### 桌面组件与上课设置

课表「工具」里可添加 **今日安排**和**下一项安排**组件。前者展示多项日程，后者突出当前或下一项。接水页可添加 **接水组件**，在桌面上下滑动切换已保存设备，并发出接水请求。组件尺寸与手势表现受桌面启动器影响。

在「我的 → 课表设置」可开启以下功能：

| 设置 | 说明 |
| --- | --- |
| **课程上岛（测试）** | 状态栏实时卡片显示课程简称和教室。可设置提前时间、课程别名、信息密度，以及持续到上课、下课或自定义时长。 |
| **上课自动免打扰** | Android 10 及以上可用。开启后按课表时段进入免打扰，安排结束后退出。晚自习和自定义日程各有独立开关。使用前需授予禾序勿扰访问权限及「闹钟与提醒」权限。 |

课程上岛尝试适配 Android 13 及以上的 vivo／iQOO 原子岛和小米系超级岛，以及 Android 16 及以上的 OPPO／一加／真我流体云与支持「实时更新」的 Android 设备。具体机型、系统授权和显示形态可在设置中用「试发 2 分钟」检查。

### 界面与质感

「我的 → 界面与质感」可切换 **清爽校园、极简阅读、柔和原生**。夜间模式可手动设置或跟随系统。底部导航支持点击和手指拖动切换，液态玻璃的通透程度和点触光感可以单独调节。

## 账号与数据

- 校园账号、学习通和 798 分别登录。禾序在手机上与各服务通信，可在「我的 → 自检诊断」查看相关连接状态。
- 校园密码和登录票据由 Android Keystore 保护的本地加密存储管理。已保存的校园密码在原生层按账号复用，登录页只显示掩码。可在「我的」删除已保存的校园密码。
- 学习通密码用于登录，本机保留登录所需的会话。自定义日程、课表缓存、组件设置和已同步的部分账单保存在本机。清除应用数据或卸载会清除这些本地记录，重要日程可先导出。
- 二维码识别在设备上进行，扫码使用的相册图片和摄像头画面不会上传。需要联网的校园数据和设备操作以各平台实际返回为准。

加密存储、数据来源和签名的进一步说明见 [SECURITY.md](SECURITY.md)。

## 应用更新

禾序启动后会自动检查官方 GitHub Release，也可以进入「我的 → 版本与更新」手动检查和查看说明。发现新版本时，点击「下载更新」会通过浏览器从 GitHub 下载 APK，下载完成后由 Android 系统安装。GitHub 在部分网络中可能连接超时，页面提供「可加群获取最新版本」入口。

发布时请使用 `v主版本.次版本.补丁版本` 格式的正式版标签，并在 Release 下添加同版本的 `Hexu-v主版本.次版本.补丁版本.apk`。APK 继续使用原发布签名。

## 源码与构建

| 目录或文件 | 内容 |
| --- | --- |
| `java/` | Android 原生逻辑、本机服务、数据解析、桌面组件和系统通知。 |
| `assets/` | WebView 界面、主题样式和前端交互。 |
| `res/` | Android 布局、图标及组件资源。 |
| `tools/` | 构建时使用的 jsoup 1.23.2 和 R8 8.6.27。 |
| `AndroidManifest.xml` | 应用包名、Android 版本与权限声明。 |

构建环境需要 **Python 3.10+、Node.js、JDK 17+、Android SDK Platform 36 和 Build Tools 36.0.0**。通过 `JAVA_HOME` 和 `ANDROID_SDK_ROOT` 指定本机路径。Windows 下，维护者使用下面的命令生成正式签名包。

```powershell
pwsh -NoProfile -File ./build-secure.ps1
```

正式包签名由维护者单独管理。开发者本地打包需要使用自己管理的签名配置。直接体验请下载 Releases 中的 APK。
